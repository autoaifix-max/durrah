# درة العنب — نسخة العرض التفاعلية

Next.js16.4.1 App Router وReact19 وTypeScript، بتصدير ثابت ودعم عربي RTL وخط Tajawalمحلي وهوية وصور العلامة المعتمدة. الواجهة للجوال والآيفون أولًا.

## التشغيل والبناء

```bash
pnpm install --frozen-lockfile
pnpm dev
# أو النسخة المبنية:
pnpm check
pnpm test
pnpm build:static
pnpm preview
```

المنفذ PORTأو3000،والخادم المحلي على0.0.0.0. المخرج`out/`؛لا يستخدم`next start`مع`output: export`. أدوات التحضير والتحقق تولد المسارات وصورالتخزين المحلية وتتحقق منHTMLالعربي والأسعار و404والأصول.

## صفحات العرض

الرئيسية`/`،قائمة`/menu/`والمنتجات9تحت`/menu/[slug]/`،السلة`/menu/cart/`،الفروعالتجريبية`/menu/branches/`،إكمالالطلب`/menu/checkout/`،التأكيدوالتتبع`/menu/tracking/`. المنتجات9والخيارات34منمرجعاعتماد16أكتوبر2026. الفتةوالكبةلهماصورةمشتركةللتصنيفمعإفصاحصريح.

`client/src/data/menu.ts` للمنتجات والأسعار؛`data/demo.ts`للنموذجوالتحققوتسعيرالسلةمنالمرجعلاالتخزين. `components/demo/DemoProvider.tsx`يستعيدحالةمحليةبعدSSRويتيحالإضافةوالتعديلوالحذفوالتأكيدوالتتبع. البياناتتُحفظفيlocalStorageبمفتاح`durat-demo-v1`،ودونبياناتعميلأوبطاقات. تعذّرالتخزينلايشغّلخدماتبديلة؛تبقىالتجربةفيذاكرةالجلسة. السلةحد99للخيارقيدعرضفقطوليستسياسةمبيعات.

لاAPIأودفعاتأوإرسالطلباتحقيقية. بياناتالعميلالمعروضةتجريبيةثابتة. خياراتApplePayومدىوعندالاستلاممحاكاة؛لاخصمولاcardfields. تأكيدDEMOمحليوتتبعالمراحل يدوي من أزرار العرض، لا حالة فرع أو مندوب. الضريبةوالتوصيلغيرمحسوبينولاتوافرمؤكد. السجلات9الفعليةناقصةأسماءوعناوين؛تُعرضمرقّمة«فرعتجريبي»وتقبلالبنيةنموالفروعلاحقًا.
