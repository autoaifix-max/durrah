# درة العنب — صيانة نسخة العرض والربط المستقبلي

## النسخة الحالية

موقع Next.js 16.4.1 App Router وReact 19 وTypeScript، بتصدير HTML ثابت وخط Tajawal محلي. الرئيسية والهوية والشعار SVG وصور الواجهات والداخل والقائمة المعتمدة محفوظة. المنتجات تسعة، وخياراتها 34 من اعتماد الأسعار بتاريخ 16 أكتوبر 2026، دون أسعار أو عروض جديدة. صور الفتة والكبة مشتركة للتصنيف مع إيضاح ذلك؛ لا صور مولدة مقدمة على أنها تصوير حقيقي.

وافق المستخدم في 22 أكتوبر 2026 الساعة 05:00 على تنفيذ محاكاة ونشر نسخة العرض للمالك. هذه الموافقة تستبدل منع السلة المحلية والنشر في المرحلة السابقة لهذه النسخة فقط، ولا تفعل أي طلب أو دفع أو تكامل تجاري حقيقي.

## التجربة المحلية

السلة تحفظ المنتجات وخيارات الأحجام والكميات على المتصفح تحت مفتاح `durat-demo-v1`. يعاد اشتقاق السعر من بيانات المنيو دائمًا، ولا تقبل الأسعار أو الحقول الزائدة من التخزين. حد 99 لكل خيار قيد للمحاكاة وليس سياسة بيع فعلية. الحالة تبدأ فارغة أثناء التوليد وتستعاد بعد التحميل؛ التغييرات تحفظ فورًا قبل التنقل، مع استمرار العمل في الذاكرة عند تعذر التخزين.

اختيار الفرع صريح، والسجلات مشتقة من الفروع التسعة الحالية وتسمى «فرع تجريبي» مرقّمًا فقط؛ لا عناوين أو هواتف أو أسماء فروع مختلقة. اختيار استلام أو توصيل تجريبي، وبيانات العميل ثابتة: «عميل العرض» و«05XXXXXXXX» وعنوان تجريبي عند الحاجة، دون طلب معلومات شخصية حقيقية.

Apple Pay ومدى والدفع عند الاستلام اختيارات محاكاة؛ لا حقول بطاقات ولا خصم أو تحصيل. التأكيد ينشئ طلبًا محليًا يحمل `DEMO-` ويمسح السلة، ولا يرسل لأي فرع أو جهة دفع. التتبع يتحرك يدويًا بأزرار المحاكاة ولا يعكس حالة مندوب أو فرع. إجمالي المنتجات لا يحتسب ضرائب أو توصيلًا؛ لا توافر مؤكد ولا فاتورة ضريبية أو إثبات دفع.

يستخدم العرض روابط HTML عادية بين صفحات Next.js المصدرة بدل جلب RSC الاستباقي، بعد ظهور خطأ وصول في WebKit أثناء التنقل السريع. تبقى تفاعلات السلة والخيارات محلية، وتستعاد عند تغيير الصفحة. هذا اختيار خاص بالتصدير الحالي؛ عند إضافة خادم وتكاملات معتمدة لاحقًا تراجع استراتيجية التنقل.

## أودو وفودكس وواتساب

لم تُنفذ API أو OAuth أو مزامنة حقيقية. المعرفات الخارجية `null` ومزود البيانات محلي، وحقول تفعيل الطلب والدفع الحقيقيين ما زالت `false`. واتساب بلا رقم معتمد أو قناة آلية؛ لا رسائل ولا روابط محادثة فعالة. وجود ملفات Express وtRPC وDrizzle القديمة ضمن القالب لا يعني تشغيل خادم أو قاعدة بيانات.

الربط اللاحق يحتاج نطاقًا معتمدًا وخادمًا لحفظ المفاتيح ومحولات منتجات وفروع وأسعار وخيارات وتوافر ومزامنة ومعالجة أخطاء. السلة المحلية ليست بديلًا عن نظام طلبات إنتاجي. البيانات التجريبية ليست سجل عملاء أو معاملات، ولا ينبغي تحويلها إلى طلبات فعلية عند تفعيل الخدمات.

## النشر والتحقق

نشر نسخة العرض معتمد، دون شراء نطاق أو حملة أو إرسال رسالة للمالك مباشرة. `noindex` مستمر لتجنب الفهرسة؛ ليس حماية وصول والرابط قابل للمشاركة. يدفع الإصدار النهائي إلى canonical main بعد الجلب والدمج والفحوص، ثم يتحقق من نجاح نشر نفس الإصدار قبل تقديم الرابط الحقيقي.

نجحت فحوص TypeScript والاختبارات الثمانية والثلاثون وبناء Next.js والتصدير والتحقق من الصور والخيارات والمسارات و404. فحص رحلة العرض محفوظ في `scripts/test-demo.py` ويشمل السلة واستعادتها واختلاف الأحجام والحذف والفرع وطرق الاستلام والدفع الثلاث والتأكيد والمراحل والاستعادة وإفراغ السلة، مع رصد الطلبات الخارجية والأخطاء والتمرير الأفقي. النتائج محاكاة WebKit/Chromium، وليست اختبارًا على آيفون فعلي أو داخل واتساب/إنستغرام؛ لا ادعاء قياس سرعة أو أحمال فعلية.
